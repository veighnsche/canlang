# Build company apps with CanLang

CanLang describes a business application in typed source: its records and rules, user operations, and interface. The compiler derives checked interfaces and runtime behavior from those owning declarations. Use this handbook to author complete applications, review their authority, and operate their workflows.

## Choose a path

Start with [installation](02-installation.md), then build the complete [Tasks app](03-first-app.md) and extend it with a [guarded workflow](04-first-workflow.md). The language chapters explain source and values; [data](../03-Data/01-models-and-relationships.md), [access](../04-Access-and-rules/02-roles-and-operation-permissions.md), and [workflows](../05-Workflows/02-scenarios-and-effects.md) own their deeper rules. See [AI authoring](05-ai-authoring.md) for a review loop with a coding agent.

## Find a topic

Use [the syntax reference](../12-Reference/06-syntax-reference.md) for declaration forms and [types and builtins](../12-Reference/07-types-and-builtins.md) for exact values. Follow the relevant owner page before changing permissions, concurrency, or retention. The remaining chapters cover interfaces, integrations, generation, development, deployment, recipes, and reference contracts.
