# SYN-R06 delimiter recovery

The EOF-unclosed final join now preserves the audit's four malformed sibling cases and later module case. Each previously had complete source coverage but swallowed both handwritten diagnostic sentinels. The repaired cases retain E3002 exactly at `1 + true` and E2001 exactly at `nope`, the independent derive symbols, and the later module. Balanced controls preserve their exact original CST node kinds/spans and parse diagnostics, not merely their reconstructed text.

## Choice and support boundary

Accepted for this repair: layout first uses its ordinary delimiter scanner without changing valid joining. Only if its final pending join reaches EOF with openers still present does it replay that suffix with the same scanner. The original unmatched opener byte positions authorize recovery. While one is active, the next nonblank, non-`##` physical code or description line at the same or a lesser indentation than the current pending logical line abandons that malformed join, anchors E1102 at its innermost remaining opener, clears its delimiters, and resumes ordinary joining. More-indented unfinished continuations remain in the malformed owning line. Balanced subjoins encountered during replay retain arbitrary continuation indentation because their openers were not proved unclosed. A hash set and active count avoid rescanning the delimiter stack for each physical boundary. Joining remains two passes at most over the failed suffix, with one source of delimiter behavior.

The grammar says continuation indentation has no layout meaning inside balanced delimiters. Eager indentation resets would change accepted source. Parser-driven contextual retries could recover additional accidentally balanced malformed joins, but require shared parser/CST ownership and transactional recovery semantics beyond this packet. Deferring leaves demonstrated independent diagnostic loss. Three independently worded equivalent JEV choice requests compared all four alternatives with the same verified context and uncertainty. All three favored EOF fallback at confidence 1.0; responses are advisory, not correctness evidence, and no disagreement occurred. The stored requests describe the proposal; the implemented unmatched-opener authorization refines replay to preserve balanced subjoins.

Uncertainty remains about intent in already-invalid incomplete documents: same/dedented authored expressions may have been intended as unfinished continuations, and recovery may produce several error lines. This repair promises independently visible same/dedented boundaries only after a proved EOF-unclosed join. It does not infer declaration grammar, recover independent more-indented declarations, or fix malformed joins that are accidentally balanced by later unrelated closers. No language support, effects, types, IR, emission, packages, LSP, formatting, grammar or shared documentation changed.
