# Money constructor defaults

Accepted implementation choice: the compiler uses a Cargo path dependency on the existing private Values Rust core. `codegen/defaults.rs` adapts exact literal arguments to the owning decimal parser and checked Money constructor, then uses its canonical scalar wire codec. Currency facts, half-even rounding, int64 bounds and encoding stay Values-owned. Literal classification and wire publication share this adapter; native emitted defaults retain the original constructor call.

Three independently worded, equivalent JEV choice requests compared direct reuse, an owner facade, and a public JavaScript subprocess against the same outcomes. All selected direct reuse, with confidence .83/.95/.95 and selected probability .89/.97/.97. The first still gives a facade .11 probability. Responses provide no explanatory rationale; they are advice. The direct boundary is selected because the complete checked APIs already exist and avoids adding a facade or compile-time JavaScript host. Coupling to private owner modules remains an acknowledged maintenance risk. The first request returned HTTP503 before one isolated successful retry; that failure and all requests/responses are retained here without source attachments.

The direct production-CLI/public-Values test passed for 17 model and parameter defaults: integer major units, exact decimals, positive/negative half-even ties, zero/three-decimal currencies, int64 endpoints, reordered named arguments, nullable values, arrays, null and empty arrays. It imports unchanged emitted modules and checks executed native defaults, descriptor defaults, requiredness and owning encode/decode. This is producer/default qualification, not a new application persistence receipt. Dynamic expressions and owner-rejected constructor values retain explicit refusal. Required existing dependency notice bundles were updated and their validator passed for both advertised targets; no native/release build or activation was performed.

Focused checks passed: `money_defaults` 1/1, `operation_results` 2/2 (including overflowing model defaults and dynamic parameter defaults), and `t15a_literal_json_exactness` 1/1. Strict compiler-library Clippy passed. The old integer-constructor wire expectation was corrected from minor 25 to 2500 for `money(25,"EUR")`, matching its major-unit semantics; explicit IR minor-unit values retain their existing wire representation.

Broader S9-Q05 and canonical compiler reference completion remain with the coordinator; this component does not independently change the 48/67 count.
