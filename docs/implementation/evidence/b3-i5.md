## Implementation

**`packages/interfaces/src/http/formErrors.ts` (new).** Deny→re-render
helper: `registerFormBinding`/`formBindingFor`/`clearFormBindings`
(operation→base-form registry, L7 binds compiled descriptors here at
integration), `wantsHtmlRerender` (explicit `text/html` Accept entry or
`HX-Request`; `*/*`/absent stays JSON), `applyDrafts` (verbatim,
create/scenario from `drafts[path]`, update from `drafts.changes[path]`
+ shaped `record`), `errorOutcome` (`failed` banner), `renderFormError`
(`form()` HTML + canonical status; full-page minimal document vs
HX-fragment in a stable `#<idPrefix>-form` swap target). Unrenderable
drafts degrade per-field: `renderResilient` retries `form()`, dropping
the draft named by each `field "path":` throw (bounded, distinct
fields; non-field throws propagate to the JSON fallback).

**`packages/interfaces/src/http/operations.ts` (modified).**
`denyOrRerender` negotiates every denial from envelope extraction
onward (framing + CSRF + invoker errors) plus the catch path; early
denials (method/shape/content-type/unparseable/sessionless) stay bare
JSON. HTML answers carry `Vary: Accept, HX-Request`. Re-render failure
journals an incident and falls back to JSON, never a 500. The JSON path
is byte-identical to before (existing suite green unmodified).

**`compiler/src/policy.rs` (new).** `policy_dump(db, program, files)`
walks the CST for `role`/`policy`/`invariant`/`crud`/`scenario`,
qualifies names via `CheckedProgram` symbols/modules (resolve) and
renders scenario param types from `TypeTable::symbol_types` (types);
predicates are verbatim source slices. `policy_dump_json` emits the
versioned dump consumed by `policyPage.ts`. Unit tests call the pub
function directly (minimal source + ExpenseFlow golden).

**`compiler/src/codegen/js.rs` (modified).** `appDefinition` gains
`forms:[{page,operation,fields,display?}]` (page `form` nodes in source
order; unresolvable targets skipped, loud in the page lowering) and
`policy:{roles,models,operations}` (role canonicals, per-model
read/invariant/lock rule ids, per-operation `by` spellings + `requires`
count + crud `when` + `gated` marker for non-role gates). Both members
are omitted when empty: sources without page forms or policy content
emit byte-identical output (pinned by the `b3_i5` plain-snippet test).

**`packages/ui/src/policyPage.ts` (new).**
`policyDumpSections` maps dump→`ReviewPolicyView` (models, then
operations with one entry per `require` so no glue strings, then
roles); `policyPage` renders one section per entry through `review()`.
Zero invented policy wording; malformed dumps throw.

**Demo `examples/expenseflow-demo/` (new).** `demo.mjs` (handler +
`--serve`-less direct-run server on 4571; test-double deps, L3
stand-in invoker failing non-positive amounts with `/amount`
field errors), `prove.mjs` (in-process proof), `expenses.policy.json`
(compiler output, byte-identical to the golden pin, 2651 bytes),
`README.md`.
