Frozen planning contract; implementation deferred. This packet releases independently of the other N01 profiles. Target/caller qualification and original prerequisites remain open. Source hashes, dependency requests and complete envelope templates are in [numeric-contracts.json](numeric-contracts.json); the shared recipe is in [numeric-common.md](numeric-common.md). The exact JS primitive planning capture is indexed separately in [oracles/manifest.json](oracles/manifest.json); it does not certify native/Wasm/public-envelope parity.

**Owner/release:** R1; independent of both numeric profiles. N04's original A04.5 depends on A04.1/A04.3/C03.ready, with A04.1 and A04.3 currently partial. A helper-only contract/proof can release independently; it cannot close A04.5 or default native scalar adoption.

**Exact seam/domain:** `packages/values/semantics/src/codecs/numeric.rs:155`, `json_stringify(&str) -> String`. Admit every well-formed Rust UTF-8 string (Unicode scalar sequences), including controls, quote/backslash/slash, all BMP scalar ranges, astral characters, U+2028/U+2029, U+FEFF, combining sequences and noncharacters. Expected output is actual JS `JSON.stringify(s)` on the equivalent scalar sequence. Quote/backslash escape; C0 use the present five short escapes and lowercase `\u00xx` otherwise; slash and non-C0 Unicode remain raw. No Unicode normalization, ASCII-only escaping, HTML escaping or alternate hex case.

**Selected mechanism/error envelope:** use existing serde_json's string serializer only (`serde_json::to_string(text)` with concrete `str`). Preserve the helper's String return type and allocation behavior. The wrapper may assert the concrete str/in-memory serialization invariant; it must not introduce a new ValueError/Result branch, silently substitute empty text/null, swallow an error, or serialize a generic user-defined Serialize implementation. Logical string serialization is infallible; allocation failure is not a new user-visible semantic branch. No new dependency/features requested.

**Exact callers:** actual_wire first JSON-escapes then truncates to64 UTF-16 units; check_shape required/unknown-field key messages (236/255); format_path bracket keys (622); encode_money_value unknown-currency and currency-path text (699). Require complete public `decodeValue('money', wire)` failures with valid-str missing/extra keys and malformed scalar strings, plus `encodeValue('money', structurally guarded unknown-currency carrier)` errors and path keys from owned scalar/encode contexts. Preserve path segment types and violation ordering, absent actual/expected fields, full ValueError/SchemaError envelopes as specified in profile1. Rust internal path helper is private; external scalar API starts at [] and supplies internal currency/minor paths. Arbitrary nested public path-key checks need original whole-validation prerequisites, or a test-only same-module helper witness with explicitly narrower scope; do not invent a public scalar-path API.

**Corpus recipe:** each of U+0000..U+001F alone and surrounded by printable Unicode; quote, backslash, slash, empty, C1/DEL, U+2028/U+2029, U+D7FF/U+E000/U+FFFF, U+10000/U+10FFFF, combining sequences and emoji; mixtures including all C0 characters; lengths63/64/65 *after JSON escaping*, both sides of short versus six-byte escapes, and astral pairs ending before/at/after the64-unit cut. Expected output units come from actual JS, not the current escape helper or serde. Immutable fixture stores input units/scalars, quoted-output units/UTF-8 bytes and complete caller output/error fields. Add mutation controls for escaped slash, uppercase hex, escaped U+2028 and truncating before escaping.

**Explicit residuals:** Rust str cannot represent lone/reversed/unpaired JS UTF-16 surrogates. Existing truncate backs off to63 units when unit64 splits an astral pair, whereas JS slice retains the lone high surrogate. Include that case as a tagged expected mismatch in the residual corpus, not a passing parity row or normalization. The untruncated escape helper must still agree for that valid-str input; only its actual_wire composition is outside the cross-JS admitted parity profile at that cut. Record current Rust result and actual JS units separately. Do not use lossy U+FFFD conversions to compare them. Original owned-input TextUnits is already lossless, but N04 does not redesign numeric Value::Str/String or whole-input transport. A04.5 requires a later lossless solution or a separately approved/preselected retained TS route before effects; this document selects neither new policy. Already retained TS/excluded domains continue serving.
