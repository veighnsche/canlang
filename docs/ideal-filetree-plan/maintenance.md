# Maintain one living plan

Refresh this plan against the last reconciled **source baseline**, not the last documentation edit. Compare accumulated source, dirty changes, contracts, public APIs and product requirements. Update only affected inventory/unit maps/reviews/finding disposition/ownership/tree/tasks/lanes together; reuse unchanged evidence only at its actual scope.

After a real source merge, record its resulting source identity and semantic delta, including a no-structure change. Absorb completed work into its owner; do not keep completed overdue/CI-release repairs as pending tasks. Retain historical reviews/data with explicit source bounds, rather than relabeling an old PASS current. Newly proposed splits need their real caller/private-state/import/install closure.

The audit documents themselves are not code acceptance, permission to implement, or a reason for bookkeeping commits/repeated product checks. Run the provided read-only link/tree checker after meaningful plan changes; separately reconcile one inventory row per original path, exact target retention/successors and task coverage. Stop when the requested planning deliverable works.
