Convert UTF-16 text/keys, f64 bit patterns (including negative zero/overflow), exact strings and absent/undefined/null/update/drop tags once at the current validation point. Rust traversal issues demand-ordered host-predicate requests; it cannot preflight later predicates or swallow getter/host exceptions.

Plans live within owner scope and generation, requests within one call. Release requests after success/materialization, replay, denial, business failure, thrown predicate, cancellation/disconnect; release plans/defaults after owner unload. Trap, ABI/version/init failure and budget exhaustion publish no partial result and do not re-run the operation under another backend. Missing selected Rust assets fail startup; planned unselected TS remains valid. Proposed limits in V07 are new-path hypotheses, not existing Can limits; a narrowing rollout requires an explicit contract decision. Existing receipt hashes/schema/defaults/public class identity do not migrate accidentally.

Host compatibility remains REQUIRED: arbitrary `unknown`, accessors/proxies/cycles/symbols/custom prototypes, sparse arrays/custom iteration, `toJSON`, repeated property reads, first/accumulated-error order, synchronous throws, callback order/termination, original `min/max` object identity, default/sentinel identity and mutable hand-built schemas keep TS paths until equivalent trace proof. ## Strongest alternatives against the same outcome

1. **Prepared TS only:** lowest delivery/conversion risk and strongest public JS compatibility; still delivers correct concise `.can` apps if compiler/runtime joins work. Cost: repeated exact arithmetic/interpreter mechanisms may lack native reuse/performance. This remains the fallback winner absent measured whole-call benefit.
2. **Private Rust/Wasm exact + owned profiles with TS compatibility:** strongest exact/native reuse and one shared arithmetic core while preserving authoring/public carriers. Cost: transport/UTF-16/host predicates/asset init, copies, duplicated comparison path and lifecycle. Select per actual owned workload after parity/resource/delivery evidence; never by leaf benchmark.
3. **Full VM or opaque Rust values/compiler reuse now:** can retain expression intermediates and amortize crossings. Cost: new lowering/execution/identity/debugging/public compatibility scope with weaker current proof. DEFERRED, not a disguised simplification of the package port.
4. **Source-only descriptions:** cheapest metadata for a single-language internal audience, but discards requested optional translations and their actual internal reference audience. The accepted shared-description reference uses deterministic extraction/static locale selection; AI guides add teaching value but nondeterminism/review/publication decisions and remain deferred.
