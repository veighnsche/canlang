1. Select TS/native and supported asset profile before semantic evaluation. Resolve/verify native executable and protocol/release metadata before a selected native job; unsupported, missing, corrupt or wrong-architecture selected output fails visibly. One native process retains tree/index/module buffers throughout a job. 3. Deploy artifact acceptance precedes environment requirement, companion reads and compatibility. Reasons keep contracts/language/capabilities/bindings/secrets/schedules order. Bare deploy refuses at the existing confirmation point before activation/Bun; preview and confirmed proceed. No eager reads to fill transport objects.
4. Existing activation produces the verdict. Native inventory/checks then follow bundle order above. Host performs separate coarse Bun-MCP and interfaces-catalog phases only when requested. Worker-main-missing preserves loud legacy fallback with neither Bun nor catalog. Other failures remain failures; native never substitutes successful activation or copies catalog policy.
5. Compute current plan before reading previous plan; absence means first deployment, other read/parse failures stay at that stage. Retain today's permissively admitted previous-plan extras and possible later errors. Render JSON/TOML/review once using JS-compatible enumeration, UTF-16/string/numeric behavior, key/diff order and exact newlines. Generic serde/TOML output is not a parity proof.
6. Preview, including preview+yes, returns without deployment-path writes. Private temporary staging is permitted. Confirmed compiler mismatch refuses before publication. Confirmed matched output publishes exactly reviewed staged bytes/config, then existing host Wrangler apply runs once. Failed apply reports actual outcome and manual recovery; existing partial-publication behavior is not described as transactional.
7. Every process exit, protocol EOF/length/stage/token error, crash, timeout or cancellation terminates the native session, invalidates tokens and removes its private staging. Containment/hash/length/path/symlink policy is explicit; resource limits on the new private process do not silently narrow the legacy language or arbitrary public helper domain.

Retained public TS helpers can accept arbitrary JS objects with observable property/proxy access or caller callbacks. Only proven inert/parser-owned snapshots cross this transport. Do not freeze/clone/enumerate arbitrary objects to claim ownership, eagerly evaluate callbacks, shadow-run effects, or retire TS helper code merely because the CLI port passed. Preserve exposed identity/freeze/presence/error/order behavior per caller. Native job conversion and host materialization costs belong in whole-job measurements.
