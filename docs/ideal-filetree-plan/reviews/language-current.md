## Workflow traces and failure boundaries

1. **Compile/check and saved joins:** `cli/compile.rs` freezes source/saved roots and analyzes with the actual catalog; Given/Then join failures remain diagnostics before executable artifact publication. `analysis/check.rs` preserves source pass order/completeness; `codegen/mod.rs` retains source owner and emission gates. Shared model-rule collection now validates/rebuilds original rule IR once, with independent declaration/unique inventories.
2. **Source proof to runtime:** source context rechecks the exact cohort, lowers the original and compares owner/callee/schema/phase; private collectors seal consumed closure before emitter transport. Query-only partial lowering does not manufacture permission to run an incomplete artifact. `cli/compile.rs` merges returned emission diagnostics and refuses artifact publication when errors remain; the public `codegen::emit` API still requires its callers to merge analysis/load/emission errors, rather than assuming every returned artifact is executable. State/Work still check current authority, original DATA source, owner stage and real admission independently.
3. **Saved contract to wire:** the Given child checks declarations and canonical producer selection without executing generated implementation to discover authority. The descriptor child serializes already-checked IR/types/catalog; its reexports preserve prior import paths. A typed wire record remains nongrant metadata, not an admitted call/session.
4. **Generation custody:** `cli/generation.rs` owns the saved local module closure, normalized relative paths, no bare/Node/file/require/nonliteral edges, UTF-8/missing-file failures, fingerprints and lease publication transitions. Shared locators/readers remain defining once. The source scanner is an existing finite admission profile, not a promise to accept unrestricted JavaScript.
5. **LSP/editor:** retained source/version snapshots govern diagnostics and edits; bounded framing and physical/UTF-16 conversion remain independent obligations. Existing real-server versus stub-analysis subjects and packaged editor installation remain distinct evidence classes.
6. **Native dev:** parent Owner selects current generation; workers consume fixed tickets and report capture/compiler/service facts. Preview gates exact compiler output before allocation; private SDK transport checks path ownership, alias/mode/size and stable bytes. Current tests exercise actual public control, private filesystem, process-group and PTY/SDK paths. Their existence does not claim every browser/host failure branch is covered.
7. **Native Values:** compiler consumes the owner-generated currency lookup directly. JS opt-in bootstrap, bounded WASM transport, exact native operations and ordered typed error bridge stay separate from Intl/host projection. Regenerated assets establish a different output inventory; historical conformance cannot silently qualify every future host/domain.
