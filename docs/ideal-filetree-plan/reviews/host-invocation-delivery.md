### GEN-REQUEST-INTERRUPTION: a repeated interrupted request can launch again

This source defect does not prove remote duplicate effects/cost occurred; no crash or concurrency experiment was performed. Correct the existing request-ledger/lifecycle owner with exclusive prelaunch binding of request/input/attempt and conservative in-flight/interrupted recovery, preserving explicit supersession, unknown classification, fence/candidate/current semantics and exact repeated terminal outcomes.
