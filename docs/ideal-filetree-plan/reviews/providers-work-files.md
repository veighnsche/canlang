## Shared transport and controlled evidence

`httpRequest`/binary/stream validate configured http(s), positive deadline/body cap and same-origin request resolution before transport. Redirect mode is manual; every response body drains under the same cap/deadline before a subsequent hop, off-origin destinations refuse before sending there, and five hops cap loops. 301/302 POST and303 become GET;307/308 retain request/body. Authorization and idempotency headers derive from installed config/request, credentials are omitted. Origin restriction is not a provider path/graph permission policy.

One private deadline spans headers, redirect hops and buffered/stream body work. Its combined signal retains the first cancellation reason, distinguishing caller cancellation from timeout. Buffered chunks are copied before another read, then merged; no later producer reuse can change admitted bytes. Limit detection keeps the original body-limit failure while cancellation waits are bounded by the same signal. Streams reject non-2xx before yielding progress, enforce a cumulative byte cap, decode incrementally, cancel on early return and release reader/timer in finally. Logical return does not promise immediate physical remote cleanup. Binary responses retain exact bytes and an explicitly untrusted content-type claim. Pages reject unsupported/over-limit requests before loader invocation and validate every returned item/cursor; pagination does not authorize the domain.

Transport metadata alone cannot classify acceptance. Mail/models/judgments/media each map408/429/5xx/timeout/network/redirect uncertainties in their own operation context. A200 with an invalid declared response becomes a typed failed completion; it does not silently leave pending. Safe result/errors never echo arbitrary provider text: `specificOrGeneric` chooses fixed category-specific explanations, with generic fallback; regex scrubbing alone is not proof of disclosure safety.

Controlled servers accept finite scripts; the portable admission checks provider/kind/allowlisted keys, JSON safety, HTTP status and delay/count rules. Media canonical base64 is decoded separately with a round-trip check. JSON-safe scripting remains a trusted fixture domain, not a sandbox for hostile Proxy traps or arbitrary executable objects. Shared references are conservatively treated as cyclic by that admission walk. Controlled readers cap request bytes at4,000,000; logs keep request bodies for local test inspection and record only presence of Authorization. Mail tracks idempotency keys and original lookup results; Ollama streams exact scripted NDJSON and tracks sockets/timers; System One returns scripted batch bodies; Comfy records prompt IDs, history/view bytes and targeted cancel status. Closing harnesses destroys sockets and clears model/mail timers. None proves a vendor supports this release contract or authenticates inbound webhooks.
