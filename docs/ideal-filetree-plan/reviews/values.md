## End-to-end source traces

### Exact representation and operation semantics

`numeric/integer.rs` requires raw BigInts before computation, compares unrestricted values without narrowing, and narrows arithmetic results once. Signed minimum modulo minus-one is calculated on BigInt and returns zero. `numeric/rounding.rs` uses exact quotient/remainder and symmetric half-even ties. `numeric/decimal.rs` retains stored coefficient/scale (including signed-zero scale), aligns add/subtract, rounds multiplication only above18 places and repeating division at18 using guard/sticky digits, and distinguishes construction range errors from computed-result overflow. A finite terminating quotient keeps its minimal scale. Numeric equality ignores scale; the public carrier still exposes stored scale.

Money distinguishes `makeMoney` structural construction (no minor narrowing), shape-only `isMoney`, checked currency-table membership, and arithmetic result checks. `divideDecimal` has a deliberately weaker structural money/money ratio branch than `moneyRatio`; normalizing both through one stronger constructor changes accepted errors/domain. `money(value,currency)` checks currency before value, computes exact minor rational and rounds once. Addition/comparison demand matching currencies; equality across currencies is false. `sum_int`/`sum_duration` collect exact totals before one narrow; decimal sum first validates every element, selects scale, then sums; explicit money currency validates before elements, while inferred empty money refuses. Public `array.ts` remains responsible for actual JS iteration and original objects: the owned Rust vector cannot prove callback/custom iterator/accessor equivalence.

Temporal civil math uses proleptic Gregorian floor division, year1–9999 range checks, month-end clamping and ascending half-open iteration. Equal `dates` endpoints still check limit type before ignoring its value. Public datetime constructor accepts explicit offsets, lowercase t/z and arbitrary fractional precision only when all submillisecond digits are zero; scalar wire accepts exactly uppercase UTC with three millisecond digits. Leap seconds and nonzero submillisecond precision fail. Duration division by int requires exact milliseconds; a duration/duration decimal ratio has its separate operand narrowing rule. Do not collapse public parser and wire grammar or result-only and entry-narrowing rules.
