# Stable slices and completion matrix

A slice names an existing responsibility, not a new package or service. The [catalogue](../catalogue/inventory.md) is the exhaustive path map; primary reviews below own exact source selectors, actual test assertion subjects, workflow traces, intended-model constraints and remaining unknowns. The [draft catalogue](../catalogue/draft-inputs.md) retains independent child identities. These short cards index that evidence rather than creating competing allocations.

## Four dimensions

Path accountability is complete. Whole-product substantive duty review and workflow qualification are partial. Independent challenge is complete for selected consequential boundaries, partial for all retained behavior. Exact allocation is complete for all current retained leaves, including implemented successors. Semantic and compatibility corrections remain gated; no unimplemented extraction is allocated by line count. No fresh product behavior was executed. Source traces are source evidence, not runtime qualification.
