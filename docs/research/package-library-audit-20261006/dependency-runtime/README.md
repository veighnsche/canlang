## Upgrade risks and maintenance work

1. **Prove delivery correspondence before comparing library complexity.** Preserve the source repairs and narrow historical acceptance. A fresh private current-source emit/pack and actual resolved consumer must precede a stronger delivery claim; internally coherent stale assets are insufficient. UR01 is a qualification risk, not a deployed corruption claim.
2. **Trace entry-specific dependency closures.** Eager Node roots pull development or SDK machinery into commands that may not use it. Evaluate separation only against actual callers, first failure/API behavior and measured startup; do not create another forwarding layer just to hide dependencies. Public SDK wildcard subpaths used by Can exist locally; unused SDK package-root files do not.
3. **Reduce layout/output coupling where equivalent contracts permit.** The bundler reads exact package versions/export-object/entry paths, stages single-file library entries, duplicates some SDK/identity bundles and rewrites trusted producer source literals. Cookie attribute rearrangement, CSV error identity and import/map/library output assumptions need explicit upgrade controls. Vendor rewrites or repeated Error class identity require caller evidence, not a speculative blanket replacement.
4. **Qualify actual hosts and joins.** Generated wasm-bindgen ABI/first-instance behavior, workerd optional platform binaries/postinstall, Node versus Worker native comparison, Browser initializer/HTML/resource activation, SDK negotiation/post-handler validation and current-source installed build are distinct gates. Same-name assets or successful import/401/factory/one ABI vector cannot close them.
5. **Keep unfinished and held scopes truthful.** Work Rust registration still lacks delivered bindings/selected consumer. Held native preparation availability/hash/target/license/release inventories and build ordering stay separate. No default-native switch, TS removal or held implementation is proposed as an automatic cleanup.
6. **Count duplication only in delivered graphs.** Bun lock has 298 records/270 names and seven multi-version names (including Node types). Cookie has three versions; lexer/MagicString each have old/new versions; trace-mapping also differs. The four Cargo roots have no within-root duplicate version of a crate. Build/dev/types, independent native tool profiles and transitive copies are not by themselves duplicate production bytes or a reason to collapse versions.

The independent browser challenge also found a future DOM join mismatch: WindowLike requires visibilityState and passes itself to polling, while visibility state belongs to Document. A raw window does not satisfy that property contract; a valid injected visibility port does. The actual join must observe document visibility before activation is accepted. This is a source-derived conditional finding, with no mounted caller or browser execution. [MDN Document.visibilityState](https://developer.mozilla.org/en-US/docs/Web/API/Document/visibilityState) confirms the property owner; [counter-review](counter-review.md) records the exact source locations. No additional adapter or signature redesign is selected.

The [Cloudflare](packets/cloudflare.json), [Values/Work](packets/values-work.json) and [browser/identity/Interfaces](packets/browser-interfaces.json) packets preserve counterevidence, exact anchors and original crosswalk IDs. Retained security/lifecycle refusal, cancellation, containment and partial-effect findings remain in their owning audits; this audit does not duplicate or close them.
