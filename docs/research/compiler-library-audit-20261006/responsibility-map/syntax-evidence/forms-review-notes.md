## Findings and review limits

- **Generic UI is not the declared closed catalog admission contract.** Rust `parse_ui_piece` sends any unrecognized nested UI word to `parse_catalog_item`. That function parses arbitrary expression-valued attributes, rejecting duplicates but not unknown profiles. `types::walk_ui_page` validates generic positional domains while its comment leaves options untyped. `ir::decode_catalog` has selected binding adapters and a generic factory fallback. `js::is_ui_factory` admits only 20 of the 68 catalog source words after the `chat_bubble` → `chatBubble` spelling adaptation. This count concerns direct factory availability, not per-component binding/appearance completeness; `calendar` is additionally selected as an agenda by core syntax rather than proving its declared date-control profile. Unknown names and many declared components reach E6008 downstream. Core board/calendar/gallery and inline preference panels also lack JS factory admission. The focused profile packet is proposed, not an implementation/policy selection.
- **Corpus and judgment acceptance outpaces semantic ownership.** Corpus parses required attributes but is absent from resolve indexing, type phase2 and effects declaration dispatch. Judgment indexes a fieldless contract and is tracked specially; judgment binding/type paths are poisoned rather than a typed evaluate/result interface. Generic emitted record shape cannot establish judgment execution. Explicit unsupported diagnostics or complete owning semantic tables are proposed alternatives, with no choice made.
- **Parse/check/lower status must stay separate.** Decimal literal is typed and reaches `IrExpr::Decimal`, then JS `lower_expr` emits E6008 and a throwing placeholder. Value queries have no lowering for order/archived or async filter/projection callbacks, while synchronous where/select and stored query paths have owners. Preference ordering parses structured syntax but collection lowering passes the order record to `selector_strings`, whose unsupported-node fallback returns an empty array, losing the by/default/cases contract. Runtime-driven preference ordering is unqualified. `Tab` also falls through `decode_ui` with empty props/children: its admitted factory does not preserve caption/descendants. This is a focused probe lead.
- **The independent Python prototype is not the Rust compiler.** Grammar sentences saying sequence/preference-order/form CSV/page refresh/CRUD expose/structured derived labels are absent from the initial prototype do not establish Rust rejection. Current Rust has parser entry points/attributes for them; sequence checking, IR and BDD emission are present. DESIGN's opening “compiler and runtime remain unimplemented” status is also not a reliable current implementation inventory. The prototype is pinned as a separate admission owner, with no semantic/runtime responsibility.
- **Strings and metadata need distinct scopes.** General source interpolation has no grammar production. JSON strings, attached prose/references, inline desc/legacy annotations, labels and translated message descriptors retain separate owners. ICU placeholder/pattern validation occurs in `analysis::examples` and emits message descriptors; this is not source-string lexical interpolation. Defaults/modifiers/server values and left-to-right signature-default checking are mapped separately from successful runtime evaluation.
- **Behavior examples are produced, not thereby executed.** Tables and sequences pass through examples checking and BDD emission into actual `loadExampleSuite`, `runTable` and `runSequenceSteps` consumers. Existing workflow evidence qualifies the platform CLI test gap (`executed:0`) separately. No complete scenario/fixture/BDD lifecycle run is claimed by this source audit.
- **Maintenance is not installed execution.** Migration effects/directives reach IR-time `check_migration` and metadata. Runtime mapper/activation APIs are real separately pinned owners. Their existence does not establish the complete compiler-generated backfill/installed snapshot/queued work application join.
