## Entry, authority and termination

The binary converts OS arguments to strings, calls the public CLI facade and catches Rust unwinds as tool errors. In-process `cli::run`/`dispatch` callers do not inherit the binary panic boundary. Argument parsing and per-command flag restrictions precede command bodies. Broken output pipes retain the selected exit code; other output failures panic. Library calls are mapped separately from CLI acceptance.

Source checking selects the first readable catalog candidate: explicit flag, nonempty `CAN_CATALOG`, cwd `can-catalog.json`, then cwd `packages/values/dist/catalog.json`. Unreadable candidates are skipped, even explicit ones; the first readable malformed candidate stops admission. Checking continues with partial recovered syntax and diagnostics. `check_program` returns checked tables plus diagnostics without a completeness envelope. `CatalogAnalyzer` invokes all passes and claims `CompleteInputs::all`; completeness means passes ran, not that input is valid. Check/lint/docs/policy gate errors rather than independently gating `complete=false`. Compile additionally uses emission's completeness gate. Direct callers own matching source, checked tables, catalog and all returned error gates.
