# Pass 7 host and dependency qualification

This profile compares the final Pass 7 compiler with the final Pass 6 stripped release snapshots. `baseline-parity.json` verifies all 41 core/Cargo inputs plus `build.rs` (42 total) against committed HEAD blobs, the Pass 6 copied compiler, and its saved manifest before reuse. Working tree changes are excluded from that baseline comparison. Baseline bytes are 2,167,152 on native macOS arm64 and 2,960,352 on Linux x86_64.

Builds use the same compiler-only isolated snapshot without `.git`; `can --version` consequently reports commit `unknown` for both sides. `examples/ExpenseFlow.can` is included for the existing golden seam. Two source-owned editor `.can` fixtures required by compile-time `include_str!` are included and hashed; full packages and the editor consumer are excluded: root qualifies their actual Node/editor integration separately. `source-manifest.json` records every snapshot input; `catalog-runtime-inputs.json` hashes the catalog/runtime seam visible in the live tree without copying dirty package sources into builds. The equivalent test-only Clippy polish copied before Linux test compilation is recorded in `test-polish.json`.

The release profile is `strip=true`, `opt-level="z"`, `lto=true`, `codegen-units=1`, with default unwind. Builds run `--offline --locked`, reusing the established native and Linux target caches. `commands.json`, `linux-final.sh`, exact Cargo files, host metadata, feature tree, and logs record reproduction inputs. Linux runs only the already-local pinned image `rust@sha256:24e632c09342c20abf8312cf4f61430a911c01ed3a5e4c02b87292b1c39c5273`, `--platform linux/amd64 --network none --pull=never`, with cached Cargo home and `CARGO_BUILD_JOBS=1`. Only the four newly added checksummed crate archives/index entries are copied from the native cache when absent; no pulls, settings changes, uploads, or unrelated dependency upgrades occur.

`added-dependencies.json` records archive checksums, licenses, declared features and lock changes. `activated-dependencies.json` records resolved features: `lsp-types=0.97.0` has defaults disabled and no active features; transitive `fluent-uri=0.1.4` has default/std, `bitflags=1.3.2` has its empty default feature, and `serde_repr=0.1.21` has none. The preexisting `bitflags=2.13.2` remains; its rustix edge becomes explicitly version-qualified because both versions coexist. Existing package versions and checksums remain unchanged. Resolved feature labels do change: the new dependencies activate serde and serde_json `default` aliases, each expanding to their already-enabled `std`. serde `derive` and serde_json `raw_value` remain enabled; no new format, numeric, or order feature is activated. See `serialization-feature-aliases.json`.

Executed qualification uses Rust/Cargo 1.99. The compiler declares Rust 1.99; this does not establish the unknown minimum supported Rust versions of lsp-types, fluent-uri, or bitflags, whose packaged manifests omit rust-version. serde_repr declares 1.71. Windows path handling remains source-only qualification; no Windows executable was run. Footprint results do not establish runtime speed improvements.

The initial Linux integration compilation exposed two omitted `include_str!` fixture files. They were copied and added to the exact source manifest, then all five integration targets were rerun with `linux-integration.sh`. `linux-initial.log` preserves that setup failure. The release and 30-test `--lib lsp` run succeeded before this fixture-only correction; their inputs are unchanged.

Final stripped sizes: native 2,217,152 bytes (+50,000, +2.30717%); Linux 3,025,752 bytes (+65,400, +2.20920%). Linux has 97 successful harness entries across 30 filtered-library, 3 authoring-join, 4 B3/S4, 31 IDE, 26 admission, and 3 typed-output tests. Two B3/S4 test bodies explicitly skip the omitted packages catalog, leaving 95 executed bodies. The exact library substring filter additionally selects `source::tests::line_index_lsp_utf16`; do not equate this count with a reviewer `lsp::` filter. Final snapshot/live parity has 106 inputs and no drift.
