## Completed output and URI packet

Position/Range conversion reuses the source LineIndex; typed enums replace manually numbered values. No live symbol output exists to migrate and no capability was invented. Input/JSON-RPC admission/raw identifier spellings/framing/body bounds/fixed errors/termination remain with the released owners. Payloads serialize directly without Value or input-parser roundtrips; raw JSON is confined to admitted response IDs.

Rename edits carry the current open document version. Code-action groups carry each open target's current version, or required explicit null for unopened targets. First-seen file grouping, edit order, empty rename output, omitted empty action edit, source snapshots and stale work handling remain. Coordinate/location ordering required by the actual editor conformance harness stays; capability member placement and diagnostic params order deliberately follow library semantic DTO order. The shared formatter preserves control-string bytes.

Standard Uri values preserve the received spelling. Small typed compatibility projections preserve previously accepted String forms that fluent-uri rejects, including unescaped Unicode and malformed percent, rather than dropping results, panicking or silently tightening input. Semantic tokens retain the complete existing public Vec<u32> including partial tuples in a narrow typed adapter; typed legend values use library types. These bounded views are explicit exceptions to full outer DTO adoption.

The old display helper had only two production callers, didOpen/didChange into SourceDb; it neither loaded files nor resolved imports. Its unconditional percent/lossy loop is retired. The url2.5.8 adapter projects only explicit case-insensitive file:// forms through checked native authority and exact UTF8/no NUL. Local/localhost produce native display paths, query/fragment do not become filenames, and dependency dot/escaped-separator semantics are deliberate. Unsupported authorities/invalid decoded bytes and all non-file/file:/relative forms keep their original URI text. Authored wire/routing identity never uses this display projection.
