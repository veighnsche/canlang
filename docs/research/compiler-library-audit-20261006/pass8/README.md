[Pre-implementation consumer qualification](consumer/qualification.md) pins the complete closure and replay.

Generated points retain JsLine vector indexes and column 0. Explicit returned library IDs preserve all SourceDb snapshots, including identical authored paths with distinct contents. Private collision-free registration keys are restored to authored display paths; first-appearance names, including repeated/empty names, remain. Missing SourceIds now emit meaningful one-field unmapped segments; the consumer still returns no original location. Malformed out-of-array old segment bytes are not an acceptance promise.

The exact field order is version/file/sources/sourcesContent/names/mappings, with all sources, explicit null contents, shared control escaping and no serializer newline. Artifact modules borrow typed maps rather than embedding rendered JSON. Existing exact ASCII `AAAAA;AACA;AACA` and typed artifact byte fixtures remain unchanged. The library exposes encoded mappings only through its full-map writer, so one intermediate metadata/mappings serialization is projected once per build. Source contents remain only in the final public map, avoiding their duplication in that intermediate.

The public decode utility has only test callers. Its small row/delta view preserves empty rows, authored order and 1/4/5-field forms while the library owns numeric parsing. Narrow alphabet/encoded-width guards and checked delta addition contain candidate invalid-alphabet acceptance and high-bit corruption observed in [primitive probes](library/results.txt). This is not another numeric codec. Error-detail changes and malformed-input correction are explicit; no unobserved panic defect is claimed.
