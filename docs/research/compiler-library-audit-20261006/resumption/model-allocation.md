# Remaining compiler model and reasoning allocation

**Dispatch settings, 2026-10-07 (Europe/Brussels).** This view assigns an explicit main model/effort and independent reviewer to every remaining named compiler reference. The [machine table](model-allocation.json) joins the existing [coverage ledger](../responsibility-map/coverage.jsonl), source ownership, current dispositions and packet prerequisites. It creates no new task identities or implementation authorization. The earlier [C-series allocation](../model-allocation-20261007.md) remains historical; use this table for the current remainder. The package repair queue has its own allocation and owner.

There are **67 reference records: 17 completed at their bounded scope and 50 remaining, continuing-checklist or qualification-join records**. These are not 50 independent implementations. OR-01 and OR-02 retain accepted finite evidence while their future checklist/wider joins still have assignments. The eight Step-9 packets retain broader open obligations, including Q07's returned-payload/request/platform gap after its fixture/facade repair.

Current completion status is recorded in the [active compiler completion journal](../../../../implementation/compiler-completion/README.md) and latest canonical ledger joins; the assignments below retain their planning checkpoint.

## Dispatch rules

The table records model, reasoning effort and independent review for each remaining reference. Use the stated phase and escalation conditions at dispatch.

- Prefer direct tooling for a cheap known command or hash. If a finite multi-step recipe needs a delegated operator, use **Luna / medium**; one fixed capture step can use **Luna / low**. An operator records results and returns failures to the technical owner; it does not invent an oracle or judge acceptance.
- Use **Sol 6.1 / low** for an already specified narrow change; **medium** for ordinary investigation/implementation; **high** only where the row identifies interacting ownership, policy, lifecycle or evaluation uncertainty. Frozen leaves get the cheaper setting shown after the main setting, once the exact recipe/expectations are released.
- Independent review has its own setting. Give the reviewer requirements, source-current artifacts and raw evidence. Reuse accepted evidence only at matching source/profile scope; combine overlapping review only when it covers the exact same outcome, not merely the same file.
- Use **Astra / medium** for a bounded evidenced conflict requiring stronger judgment, or **high** for a genuinely major open decision. Select that upfront when such evidence already exists. No ordinary packet defaults to Astra, xhigh, max or ultra, and this changes no coordinator model.
- Dispatch only compact packet/group context. Record attempts, review corrections and available usage/time. Do not repeat whole audits, restart a whole lane or run comparisons without a concrete failure/uncertainty.

## Owner lanes and concurrency

Four lanes organize ownership; they are not four simultaneous workers. With the current four-slot dispatcher, the coordinator has at most three subagent slots. Reserve a slot for independent review when needed. One exact file has one live writer. IR/JS, types, server, artifact and other shared owners serialize even when packet labels sit in different lanes. File leases come from the released closure, not from this allocation table.

- **Analysis, syntax and checked ownership:** Types/effects/resolution/recovery, stack localization, representability and source/cohort/history contracts.
- **IR, generated execution and map ownership:** IR/JS/BDD/UI/value/call/default/map consumers; package owners retain their foreign writers.
- **CLI, build, JSON and editor boundaries:** Build metadata, transport/input/output, renderer processes, docs/policy and client/workspace support.
- **Consumer profiles and release evidence:** Specified bodies/inventories, original application/host joins and public support crosswalks; no substitute mock acceptance.

Foreign package, original-app, GUI, supported-host and existing JEV/support gates stay with their owners. Current recorded writer conflicts and their limits are in the machine table; Step9 profiles need their actual released file list before parallel dispatch.

## Per-reference settings

“Frozen leaf” is conditional: the owner contract, exact writers and independent expected outcomes must already be released. For rows whose primary scope is qualification/coordination, it does not authorize implementation. The machine table records exact model IDs, reasoning names, phases, gates, evidence/source references, cheap recipe scope and escalation.
