These are evaluation proposals, not production edit authorization. Root releases each implementation packet. Inputs, executable probes and original diagnostics are retained in this directory. `fixtures/` contains all eight permanent type fixtures. Every result uses the public owner entry, and source/built owner results agree.

Further limits: no typed anonymous-descriptor or presentation-sink implementation was added or claimed. Numeric name `{0}` fails bound-signature validation in both owners for the supplied signature; this does not qualify arbitrary numeric declaration identifiers. Negative exact selector is rejected by the public owner; the compiler emits coverage noise after its branch walker abandons the signed selector. Neither observation authorizes widening the profile.
