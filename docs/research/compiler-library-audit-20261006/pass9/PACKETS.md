# Pass 9 bounded comparison packets

Release before delegation. Baseline and actual working owner inputs are hashed in `starting-inputs.json`; dirty package/shared-document work belongs to another agent. This pass compares five remaining mechanisms, not the entire repository. Each worker first traces the actual caller closure and records exact definitions, owning declarations, supported host/profile and independent expected outcomes. Public package exports/current source seams must be distinguished from private primitives and stale built outputs. Pin newly inspected inputs and dependency/API versions as evidence is acquired.

## Acceptance and release rules

Each lane saves reproducible probe/vector code, raw observations, pins, actual commands/tools, dependency/features/limits and a short assessment: adopt, retain, defer or blocked boundary. Retention is acceptable when independently reviewed; an unexecuted candidate is labelled as such. Library documentation alone cannot establish actual command/runtime parity. Existing implementation is not the sole oracle; use owner declarations/specification and independent fixed outcomes. A host-specific primitive is not a complete installed API.

Comparisons are read-only in production. No worker changes Cargo/lock, packages, shared source, decisions, living plan or Git. A concrete newly executed defect gets a finite correctness-queue entry immediately with exact source/test writers, acceptance and uncertainty. Root releases a separate repair packet before any production edits. Consequential policy alternatives require three independently worded verified-context JEV requests under AGENTS.md, saved responses and investigated disagreement. Existing released semantics or a straightforward policy-preserving change do not manufacture a new approval gate.

Use existing debug binaries/rlibs for probes and reuse compatible shared Cargo caches/targets with one build job and incremental disabled. Ask root to coordinate any candidate dependency build; do not create multi-GB per-lane targets or install package dependencies in the repository. Temporary scripts/fixtures live under /private/tmp/canlang-pass9-*; retain unique evidence and clean only task-owned redundant outputs after process/open-file checks. Record known dependencies absent from the local profile rather than declaring a fake pass.

Root integrates evidence and decisions with scoped early/often commits. A read-only comparison does not require a broad release footprint/full test rebuild; an adopted production/dependency change requires its own actual-consumer tests, review and bounded host/cost qualification. No merge or living-plan checkpoint advancement is authorized. Rowan, Salsa and JS AST/printer projects stay separately scoped; this pass starts none.
