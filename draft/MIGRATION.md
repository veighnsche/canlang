The compiler derives executable local dependencies and schema-only external dependencies from composition/import declarations; no authored source inventory is needed. A bound import uses the owner's exported schema without adding that owner's database records, UI or background handlers to the consumer. Imports grant visibility, while existing permissions and source restrictions govern invocation. Separately deployed applications additionally need installed bindings, defined delegated identity or service authority, version compatibility and result correlation. Exporting a custom capability does not automatically implement it or map it to a trusted handler.
