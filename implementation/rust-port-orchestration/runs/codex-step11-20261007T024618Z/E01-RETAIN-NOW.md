# E01 uncertain library dispositions

All eleven categories are **retain-now**. This is a bounded allocation decision: no newly evidenced simplification or blocker justifies another dependency/prototype in this release. It does not erase known correctness risks or permanently decline candidates. No consequential new semantic choice was made, so no repeated JEV consultation was needed.

| Category | Current reason | Owner and reopening input |
| --- | --- | --- |
| ICU | No evidence that a new parser reduces the known Can-extension adapter/fork burden | Values semantic owner; compiler parser owner separate: Frozen Can extensions and a demonstrably simpler compatible parser adapter; then finite Sol high/JEV challenge |
| Temporal/tzdb | Unfinished actual timezone/backend joins are not proof a polyfill simplifies the port; no target-size equivalence established | Values temporal/profile owner: One source-current supported consumer/tzdb contract and concrete bug or measured portability/maintenance benefit |
| Exact Intl rendering | No complete host+scale/grouping/bidi typed-output replacement qualified | Values locale owner: Exact string support on every admitted host with retained zeros/symbols and a concrete simplification |
| BigDecimal | New decimal layer has no demonstrated benefit over the existing short primitive under current Can bounds | Values exact numeric owner: Bounded coefficient/scale/rounding prototype only for a concrete blocker, with exact error/order/38-digit and size budgets |
| URI component encoder | Registered native URI leaves work; actual consumer/binding joins remain unfinished; no measured net simplification | Work shared assembly owner: Finite shared percent-encoding adapter with full ASCII/astral/lone-surrogate/error-order identity witnesses; actual Work consumer benefits |
| Persisted canonical JSON | RFC-style canonicalization is not current JSON/toJSON/sparse/unsafe-key contract; no authorized identity migration | State replay/CSV/export/media owners together: A source-current shared admitted contract or explicit reviewed versioned migration with stored/replay/invalid-input witnesses |
| CJS AST analysis | Import lexer does not prove free-binding scope; adding AST/scope engine has no measured current net benefit | Delivery integrator; held preparation owner separate: Specific scope false positive/negative or maintenance blocker; frozen helper provenance and real bundle negative controls before AST prototype |
| TOML | Escaping/non-bare keys are an explicit open audit risk, not silently credited correct; no byte-compatible library selected | Delivery renderer; native preparation HOLD: Demonstrated admitted control/non-bare input blocker then finite renderer contract/roundtrip packet; native preparation stays held |

| MIME signatures | Current narrow signature catalog does not justify larger async best-effort detector; this is not structural validity | Files upload owner: Authorized format expansion or specific signature correctness blocker, host/async/size and exact text/allowlist witnesses |
| Ollama SDK | No new protocol blocker or demonstrated simpler fail-closed adapter; previous upstream mismatch remains unqualified current SDK advice | Services model consumer owner: Concrete maintained protocol burden and current official SDK fail-closed/privacy/EOF/abort behavior without duplicate parser |

The original audit links and uncertainty remain in `docs/research/package-library-audit-20261006/findings.json` and its reviews. These source-based decisions do not claim present upstream-version compatibility, correct every arbitrary TOML/CLI input, or qualify held preparation. Sol high is retained for a substantive future E01 contract; fixed extraction/bookkeeping stays cheap.
