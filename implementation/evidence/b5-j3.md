## Gotchas fixed along the way

1. `PINNED_COMPATIBILITY_DATE` must be ≤ the vendored workerd max
   (`2026-08-06`): first pin `2026-10-04` failed boot; pinned `2026-07-15`
   (same date the existing workerd-booting suites use), verified by boot.
2. Literal `import("@canlang/testkit")` in the CLI breaks `tsc -b` with TS5055
   (testkit's `.d.ts` re-resolves this package's own dist outputs as inputs).
   Fixed with a non-literal specifier + structural seam type.
3. Fresh-tree ordering: `stdlib` needs `@canlang/values` dist, but values built
   last — stale-dist green on dev trees, red on fresh checkouts. Fixed by
   building joins first inside `build` (per stdlib's documented producer order).
