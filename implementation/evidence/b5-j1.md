   `opt-level="z"`, `lto=true`, `codegen-units=1`. `panic` stays `unwind`
   so `main` can catch into E7005. Release binary: **1,735,168 bytes**
   (~1.65 MiB); debug binary for contrast: 13,711,112 bytes.

   `CAN_INTERNAL_TEST_PANIC=1 can check x.can` → exit 2, no
   `panicked`/`stack backtrace`/101.

   sorted slot between E7004/E7006, array len 111→112).

## Panic-site re-verification (live tree)

  (`/dev/full`); now caught by the hook → E7005/exit 2, no trace.
- `syntax/cst.rs:235` (`token_leaf` on `Desc`): NOT reachable — every
  unclassified-token site routes through `push_tokens_with_descs`
  (`parser.rs:460`), which diverts `Desc` into Description nodes; direct
  `.leaf()` calls pass positionally classified tokens. Untouched.

  `matches!(item.kind, IrItemKind::Fixture { .. })`. Untouched.

  `codegen/js.rs`: internal invariants, all backstopped by the hook.
