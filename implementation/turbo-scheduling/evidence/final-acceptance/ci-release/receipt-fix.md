# Receipt coverage repair

The independent initial review reproduced an arbitrary one-command successful receipt accepted without revision/version/install/build/typecheck/test/cleanliness coverage. `receipt-coverage-probe.log` preserves that result.

The repair adds one finite shared `gate-plan.mjs` contract for the ten existing profiles. Runner and verifier require the same ordered steps, exact argv/CWD, explicit test identity and per-command environment. The runner records `plan_version`, source directory, temporary directory, and command IDs. Failed installs/builds retain skipped dependent rows; tests still execute after independent typecheck failure. Cloudflare/workspace preserve their explicit isolated Rust1.99.0 locked debug prerequisite and child binary environment. Native release/adoption remains HOLD.

Verification checks every required row, rejects additional/reordered/altered rows, authenticates distinct logs, recomputes test counts from those logs, requires positive passing execution for each declared test, and compares revision/version logs with source SHA and Node24/Bun1.4.2/Rust-Cargo1.99.0 pins. It retains existing receipt/GitHub-attempt/artifact/log identity checks. Native hashes remain runner-recorded evidence, with verifier syntax/path/environment checks; native binaries and source locks are not uploaded or independently re-hashed by the verifier.

Focused verification:32 tests pass, zero skips. Tests cover complete positive receipts for every profile; omission of every required command; reordered gates; extra commands; wrong argv/CWD/test identity/env; failed/skipped command rows; identity mismatches; missing/zero/all-skipped/failed summaries; falsified count labels; changed/reused/escaping logs; version and revision discrepancies; missing/failed/malformed native facts and wrong private targets/env. Injected runner tests exercise failed typecheck followed by real planned test execution, failed frozen install followed by skipped dependents, and native failure followed by test skips plus independent typecheck. These fixtures execute only mocked commands in newly created outside-checkout directories and preserve live dist outputs.

All three helper module syntax checks pass. Raw results are in `helper-tests-after.log`; `receipt-coverage-probe-after.log` records legacy incomplete receipt rejection. Hosted CI, genuine Rust prerequisite builds, native/browser/editor/alternate-host release acceptance were not newly executed by this repair.
