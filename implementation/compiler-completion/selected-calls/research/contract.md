# SEM-R03 / S9-Q01 read-only contract selection

Production files, shared docs, packages and Git were not edited. Only this owned evidence directory was written. Baselines use the actual `can compile` public CLI, freshly built `packages/values/dist/catalog.json`, and actual installed Node exports. These finite probes do not claim deployed application admission, arbitrary catalog compatibility or every formatting cross-product.

## Verified defects

- `try_overload` computes parameter slot source indexes, chooses specificity with catalog-order ties, then discards its winning binding. `order_builtin_args` independently chooses the first matching arity.
- Real named ordinary calls evaluate in parameter order. The actual production `starts_with(prefix=v.a,value=v.b)` probe reads getter-backed contract inputs as `b,a` instead of `a,b`; this is a direct callable expression-order witness, not canonical input admission.
- Both plain and message named format families check clean but emit E6008. Plain positional emission drops values. Positional/dynamic message locale is dropped. Reverse named plain formatting skips missing-placeholder analysis because `check_format_call` reads source positions instead of winning slots.
- Named message/derive calls, including a message import alias, check clean but emit E6008. Omitted declaration defaults check clean but emit missing arguments/params. The actual defaulted derive returns undefined; JSON omits its value, so the receipt must not be interpreted as a valid default result.
- Current actual stdlib reexports two-argument values `format`. Generated three-argument context calls throw `ValueError` / `invalid-construction`. Public plain control returns `Hi Bo`; values message control returns `{text:"Hoi",locale:"nl"}`.
- UI generated MessageFactory descriptors have no `kind`; values requires `kind:"message"`. Explicit options alone do not bridge them. Values' closed param kinds reject canonical `url`; values accepts exact tagged date/datetime carriers that the UI formatter does not.
- Values message options require appDefault, locale key, optional sourceLang/timeZone. InvocationContext has team.timezone, but no app default. Checked module effects retain source language and explicit locale default. The emitted registry omits locale default; Cloudflare currently hardcodes `en`. A shared package's source language is not its invoking selected app's locale default.
- Custom StateRead witness must be placed in read scenario: derive purity otherwise correctly rejects it. Its output contains awaited builtin, but actual module import fails independently because installed stdlib lacks `require`; no runtime await success is claimed.

## Recommended selected-call authority contract

1. Publish a single checked selected-call fact anchored at Call NodeKey after a successful winning match/binding. Builtins carry canonical id, winning overload identity/index and its exact slot-to-source-index mapping. Derive/message facts carry resolved SymbolId, declaration parameter identities and each supplied source-index or omitted-default slot. Source argument order is retained separately. Resolve aliases through analysis identity once. Do not classify calls by source spelling again, select another overload by arity, add an authority cache, or supply a generic reconstruction fallback.
2. Retain exact builtin arity. Catalog SigParam currently contains no default contract; overloads themselves describe allowed arities. Declaration defaults belong to owning ParamData and are distinct from nullable supplied null. Evaluate all explicit source arguments left to right exactly once, then omitted declaration defaults in declaration order using earlier resolved parameters (accepted DECISIONS signature-default rule). Do not evaluate replaced defaults. Retain lazy nested expression behavior and await only the selected target rule.
3. IR consumes the checked fact and parses only the anchored expression content. Missing fact is a loud gap even if a catalog entry happens to have matching arity. The cohort validates its source DB/catalog instance before consumption. Publishing a fact does not forgive analysis diagnostics or authorize malformed/unknown values.
4. JS may use a synchronous parameter-capture expression when reordering is necessary: source argument expressions appear once as ordered outer call arguments; the inner call references captured values in selected parameter slots. Put awaits where already required; do not add a Promise solely for reordering. Defaults may require declaration-scope bindings and must preserve earlier-parameter references and names hygienically.
5. Format post-match analysis consumes selected slots for template/values or descriptor/locale. Preserve existing exact E1202 duplicate-name, E3005 unknown/missing/overload mismatch, constructor/template errors and inner diagnostic precedence.

## Format seam recommendation and uncertainty

Three independently worded equivalent choice requests compared a complete generated adapter retaining the public facade against an additional compatible context overload on that facade. All recommend generated_adapter. Probabilities are .74/.91/.90; confidence is .48/.82/.80. There is no disagreement, but the first weak result warrants retaining interface uncertainty. The consultation is advice, not an implementation proof. Initial sandbox connection failed; the preauthorized network call succeeded with escalation. No keys are in evidence.

Keep two-argument public format and its error/output behavior. Plain source formatting should call `format(template,values)` with selected binding and source evaluation. Localized source formatting needs an explicit reusable generated bridge, normalized from checked owning message parameter declarations: values tags `text`, `enum`, `int`, `decimal`, `money`, `date`, `datetime`, preserving numeric/temporal objects, values descriptor kind, source/variants, and each bound/defaulted parameter. String-like canonical kinds map mechanically to text; qualified enum identity maps from checked enum declaration to enum. Do not guess from arbitrary type strings. Supply explicit checked selected app default/source language and trusted team timezone. Preserve the actual `{text,locale}` owner result rather than extracting `.text` and erasing provenance. This selects neither a deployed human-text sink implementation nor already-implemented provenance checking.

The specific adapter location and selected-app-default injection are not frozen. A compiler-only adapter can mechanically bridge known descriptor declarations, but cannot incorrectly pin a shared package's invoking app default. A library-owned adapter would need an explicit producer export and normalized checked kind/context contract. Extending public format would retain the desired proposed generated spelling but still require those same options/carrier/result decisions; merely removing context or only adding a third facade argument is incomplete.
