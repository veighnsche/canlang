# Independent acceptance: finite public fragment admission

Accepted for the bounded `syntax::lex_fragment` component of FAIL-R06. No implementation blocker was found. This accepts the root's precise API refusal choice, not a whole FAIL-R06 support contract or source-size/count limit.

## Source and caller closure

The five permitted files were frozen before this review and match the implementation's `source-pins.json`. `pins.json` records those inputs plus every current compiler Rust source, the manifest/lock/build inputs, and the exact linked debug/release library artifacts. `reviewed-source.diff` records the inspected change. No production source, Git state, decision, network, or cap was changed by this review.

The admission happens before the sole `lex_code_tokens` call in the public fragment function. The actual UTF-8 byte length is checked with `u32::try_from`, then the supplied `u32` base is combined using `checked_add`. An inadmissible range appends one `Diagnostic::error` E1008 at `Span::new(file, base, base)` and immediately returns an empty vector. The previous vector is never cleared or rewritten; no lexical work, partial token result, wrapped endpoint, or saturated endpoint occurs on this refusal path. Empty-at-MAX and an endpoint equal to MAX are admitted.

Within admitted fragments, every token endpoint and diagnostic offset in the shared scanner is bounded by the actual fragment byte length. Numeric/name scans terminate at or before the slice end; punctuation and unexpected UTF-8 scalar lengths are bounded by the matched remainder; closed-string decoder error bytes stay within the raw string. Consequently the admission bound protects those additions. This reasoning is for this scanner call, not arbitrary public uses of `decode_json_string` or other offset APIs.

`caller-closure.txt` preserves the current source/test search. There is one definition, one public re-export, and exactly two production calls: layout's description reference and suffix decoding. Both snapshot diagnostic length before calling and return recovery values immediately when a new diagnostic is appended, before token text is sliced or additional layout diagnostics are formed. Their bases derive from existing description spans; upstream complete-source admission remains a separate obligation. The existing focused syntax suite exercises normal description references/suffixes and their lexical/layout failures.
