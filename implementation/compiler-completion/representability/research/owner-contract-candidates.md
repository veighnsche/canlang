## Smallest finite public candidate

`syntax::lex_fragment(SourceId(0), "a", u32::MAX, &mut diagnostics)` has one byte of input and a representable base. The public signature/documentation in `syntax/lexer.rs:433-442` promises absolute spans and declares no `base + fragment.len()` precondition. `lex_code_tokens` calculates `start + j as u32` at 358 and `start + k as u32` at 421. For this case j=0, k=1: the end addition overflows debug and wraps to zero release; Span's release construction does not reject the resulting inverted span. This is source-verified, **not executed**. It is a public fragment admission candidate, not an authored-source overflow claim or a forged CST witness.

Do not call Token::text on the high-base witness with its one-byte fragment: Token::text requires the full source corresponding to the absolute span, a separate carrier precondition. Compare spans/diagnostics only. Both debug and release subprocesses should terminate normally after a selected repair and preserve fitting results. Keep current failure capture isolated before tests assert a future refusal.

A pure boundary operation could qualify `u32::try_from(length)` then `base.checked_add(length)` with 0, MAX, MAX+1 (64-bit host), and fitting/one-past sums without giant allocations. This is a **candidate operation, not an implemented/public API**. Tests of a duplicate arithmetic helper alone do not prove that lex_fragment uses it; the tiny public witness is the owning behavior gate. Saturating/wrapping offsets would lose exact absolute spans and should not be silently substituted.

Required closure before a repair: `compiler/src/syntax/lexer.rs` admission plus its existing public rustdoc, `compiler/tests/syntax.rs` public controls, and inspection of `syntax/layout.rs:646-655,692-704`. Layout's two private callers derive fragment/base from same-source description tokens. Preserve reference/suffix diagnostics, full-source token slices, recovery, and evaluation order. `syntax/mod.rs` reexports the API and `lib.rs` exposes syntax publicly. Saved `fragment-public-callers.txt` includes defining exports and all compiler/src + compiler/tests references; it does not claim unknown external clients do not exist. External direct-fragment support requires documentation of the selected out-of-range behavior. No CLI/LSP source-size policy follows: their ordinary descriptions must retain current behavior, and their refusal/lifecycle mapping must be reviewed if the selected change adds a diagnostic.

## Evidence reuse and release gate

Checked-cohort's implemented E6011 refuses foreign owners and IDs absent at original checking, including later append; it does not fix actual SourceDb ID wrap or authenticate editable tables. Frame-admission retains its selected per-frame 64MiB body/64KiB header admission, bounded geometric header allocation and EOF-before-body-allocation controls; it is not a universal compiler source/count budget. Flat-stack retains bounded actual arithmetic/logical input and traversal/destruction outcomes; it establishes neither arbitrary catalog/ResolvedType depth safety nor u32 representability.

`source-position-callers.txt` is a conservative compiler source/test inventory including unrelated `.add` methods; it is navigation, not proof that every match admits a source. Required source-byte support closure before any broader implementation includes CLI read/check/compile/fmt/lint/docs source intake (`cli.rs:678,725,802,913,1299,1679`), LSP open/change/compaction (`server.rs:843,891,945`), Snapshot::analyze, public parse_source/lex/lex_bytes/LineIndex, diagnostic and semantic-token conversion, and artifact map generation. Preserve CLI exit/diagnostic/write-before-output gates and LSP actual stdio error/notification/version/current-document behavior. Public low-level parser/layout/token/CST intake must be classified individually, not silently removed by a database guard.

Recommended next bounded choice is the finite fragment end-admission witness, if root accepts that public support obligation. Source-length/ID, semantic-table and generated-map bounds require separate selected behavior and leases. No executable low-allocation proof of actual >u32 owned source length/count exists in this work; this note does not close FAIL-R06 or claim large-input support. Root retains accepted/proposed DECISIONS.md integration and independent high review.
