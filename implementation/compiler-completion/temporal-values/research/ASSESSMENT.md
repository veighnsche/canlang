## Actual generated path versus sink limitation

Each successful generated module creates its local descriptor from the same typed value it returns, with no encoding or coercion between constructor/input and `message(...)`. The packet executes that actual constructor-and-descriptor path and separately passes the returned exact carrier through the public UI `message`/`formatMessage` join. The descriptor local is not exported, so this is **not** a generated page/browser/outbound sink witness; formatting the local generated descriptor directly would require a supported sink. No generated module is patched to expose it. The recorded import/call text and callable carrier therefore qualify the constructor seam and present UI incompatibility, but do not certify end-to-end application presentation. Browser bootstrap belongs to the separate owner worker.

Constructor admission, wire codec admission and formatter input are kept distinct. Values formatting intentionally needs tagged values; UI's present supported strings are tested independently. Authored RFC3339 constructor admission is not equated with canonical UTC wire/UI strings. No codec claim depends on these controls, and no old43-vector temporal parser run is repeated.
