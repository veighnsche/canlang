# Default JSON string bridge: proposed current-support retention

Resolve `integration:default-json-string-bridge` by retaining the supported current representation. This is a disposition for its conditional retirement proposal, with **zero production deletion and zero bridge sites retired**. It does not complete executable default semantics, Decimal presentation, or their wider compiler references. Independent review remains required.

The actual public value is `JsFieldDefault::Literal(String)` in the public `codegen::js` module; `literal_json` and `js_field_default` publish that route, and the enum exposes both `Serialize` and `to_json`. `IrDefault::Literal` already owns a typed expression; the encoded String is the artifact-default carrier, not a replacement evaluator. Its serializer revalidates once through public `RawValue`, preserving the supplied JSON token representation, rather than coercing exact scalar strings to Number or sorting/coalescing authored object members. A malformed externally constructed String returns an error through Serde serialization; the convenience `to_json` wrapper delegates to `descriptor_json(...).expect` and panics for that invalid value. Retention preserves that existing distinction and selects no new malformed-value/API policy. Existing descriptor consumers embed that typed serialized default directly; executable default lowering separately visits the checked expression.

The proposed conditional retirement deletes the encoded String/revalidation route and requires ten net production lines across the full owning closure. Making the private wire-literal tree the only public payload changes the supported enum constructor and String-returning helpers. Retaining compatibility constructors or adding a second typed variant retains the legacy route while adding another representation and exhaustive enum branch; it does not meet this mechanism retirement. Switching to generic JSON Value loses duplicate member/order/raw-number representation for supported externally constructed literals, and careless numeric conversion loses exact coefficients. No qualifying public representation revision or equivalent supported replacement has been selected. Those alternatives may be reopened under a concrete API revision; repository nonuse cannot remove the present surface.

Current finite evidence includes the complete source caller search, one RawValue parse site, equality of the selected public default/literal-tree/serialization segments against the frozen 1,152-test profile, and existing public typed descriptor tests for exact nested integer/Decimal/duration/money/bool/null values, duplicate key/order and escaped strings; unary negation/overflow/nonliteral rejection; malformed external literal Serde errors, closed server serialization tags and omission. `js_field_default` server-over-default precedence is current source behavior separately exercised in the worker's117-codegen-test run; it is not a body of the fresh ten-test descriptor/runtime receipt.
