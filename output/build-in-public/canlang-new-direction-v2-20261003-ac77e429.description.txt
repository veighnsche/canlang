I'm abandoning can-lang's broad, contract-first approach: functions with mandatory assertions, TypeScript output, and a Bun runtime, where explicit repetition was acceptable.

I'm adopting canlang: a focused DSL for custom business SaaS, organized around Given / When / Then, with canonical CRUD, authentication and pages. The new design targets workerd and Cloudflare services, PatternFly + HTMX interfaces, and generated MCP access. Compact source and shared defaults are central, with the goal of replacing SaaS subscriptions with tailored AI-built apps.

This is a new language direction in design, not a shipped compiler.
